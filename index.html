What it is

Diablo (1996), modded. Same game, same quests, same Butcher, with a visual uplift.

Same game

Nothing rebalanced, nothing “reimagined”. The quests, the monsters, the loot: all where you left them in 1996. The only thing added is running in town. Underneath, it’s still the original game, running as it always did. Brutal Diablo only changes what you see. Miss the old pixels? Press H to switch, anytime, like in Diablo II: Resurrected.

Improved graphics, darker

The game’s art, recreated to match the original. Nothing invented: the same shapes and the same frames, the way your memory says they looked.

Torches that actually light things. Shadows the town never had. Tristram at night is a different place now.

Bloodier

Every monster has several ways to die. The blood sprays, pools on the floor, runs down the walls and stays.

More gore →

In development: deaths worked out from 3D models of the monsters, so no two kills look the same. More blood, more particles.
