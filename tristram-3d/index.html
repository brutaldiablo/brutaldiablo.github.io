How it was made

In 1996 Tristram reached the screen from one side only. Whatever Blizzard North built behind it is long lost, so nobody has ever seen the back of the Cathedral.

  1. The painting

    Every wall, roof and window the game shows was measured off one picture of the town, drawn in 1996 and seen from one side.

  2. The clay

    Eleven buildings, each laid over the painting from the game’s own camera until every door and window matched the painting. Drag the divider above to see how close.

  3. The sides nobody saw

    The back of the tavern, the far side of the Cathedral, the back of Adria’s hut: nobody ever drew them. We built them from what the painting does show, the way a builder in Tristram would have.

  4. The texture

    The colours came from the game’s own art, carried round to the sides it never painted.

We made it for the mod: in Brutal Diablo the sun moves over Tristram, and it needs real walls and roofs to cast the town’s shadows. Once it existed, it felt wrong to keep it in a drawer.

What you get

  • A ZIP with one .glb file (glTF, the format every 3D tool reads), a short readme and the licence.
  • Y is up, one unit is one metre. A game tile is taken as a metre, which makes a door about two metres tall.
  • Named parts. Each building is split into walls, roofs, frames and openings, so you can paint, light or break them one by one. In a single building’s file every part has its own name.

How to open it

Unzip it first, then:

  • Blender (free): File, Import, glTF 2.0.
  • Windows: Blender, or drag it into the browser viewer below.
  • In the browser: drag the file into gltf-viewer.donmccurdy.com.
  • Godot and Unreal import the .glb as it is. Unity: add the free glTFast package first.
